| 项目 | 值 |
|---|---|

- 7.农田不再会被踩坏！
- 8.怪奇宝典：将众多指南书编为一册，可将怪奇宝典与你手中的指南书合成，手持怪奇宝典右键选择指南书，左键空气取消
- 9.若某种食材难以获取，记得去野猎商店看看

- 13.将鼠标指针放在物品栏、JEI 的物品列表、或者任意的地方上面，只要能显示物品信息即可；按键盘 B 键（可以在设置里修改），会自动打开MC百科的物品介绍页面；如果无法直接打开物品介绍界面，则会在 MC百科 里进行搜索。
- 点击右下角翻页=》

- 14.战斗动作模组为Better Combat【更好的战斗】，若影响游玩可自主删除
- 15.注意！在本包中推进Boss任务线的方式，由传统的“击杀Boss”改为制作出Boss专属菜肴。因此推进Boss任务线的基本方式为：击败Boss——制作料理——领取任务——解锁商店——再次购买Boss掉落物——制作其他物品

## 三、核心机制拆解（玩家最常问的东西）

### 1. 操作键位

| 键 | 作用 |
|---|---|
| `X + 右键` | **空手抱起生物或某些方块**（抱某些植物会出 bug，注意） |
| `~`（波浪键） | **连锁挖掘**（按住） |
| `R` | 物品栏对着物品按 R → **查看来源**（怎么获得） |
| `U` | 物品栏对着物品按 U → **查看用途**（能做什么） |
| `B` | 对着物品按 B → 打开 **MC 百科** 的物品介绍页（打不开就自动搜索） |
| `O` | 打开**商店**（也可点物品栏左上角商店图标） |
| `M` | 打开**大地图**（Xaero，可认领区块、设置强加载） |
| `Ctrl + 滚轮` | 缩放任务书界面 |

> `R` / `U` / `B` 是玩家查资料的主要方式，任务书里也适用。她可以主动提醒。

### 2. ⭐ Boss 线的推进循环（本包最核心的玩法）

**本包推进 Boss 任务线的方式，不是传统的"击杀 Boss"，而是"做出 Boss 专属菜肴"。**

```
击败 Boss → 制作料理 → 领取任务 → 解锁商店 → 再次购买 Boss 掉落物 → 制作其他物品
```

所以：打 Boss 只是第一步，**把掉落物做成菜**才是推进。料理在这里既是食物也是武器。

### 3. 经济系统（财产点数）

- 把**可出售的作物**放进**出货箱**（`xiangcaomengjia:wood_selling_bin` 木出货箱），等待片刻即转化为**财产点数**
- 财产点数按 `O` 键进商店消费；财产点数与实体货币可互相转化
- 出货箱可升级，最高**下界合金等级**（容量与售卖速度提升）
- 出货箱支持**漏斗**输入，也可与**精致存储（Refined Storage）的输出面板**相连实现全自动
- 可出售的作物会在物品上显示价格
- **商店里包含绝大部分材料**，少部分需要推进任务解锁；通过 JEI 可直接跳转到商品页面
- 食材难获取时 → **去野猎商店看看**

### 4. 七咒之戒（重要！）

- 开局会获得**七咒之戒**（`enigmaticlegacy` 神秘遗物）
- **装备七咒之戒以解锁特殊强力物品的使用权限**；本包中它的负面效果**均被移除，只剩燃烧**
- ⚠ **不要摘下七咒之戒**
- ⚠ **不要走救赎路线**
- 原因：后期强力装备对七咒之戒的【佩戴时间】有硬性要求
- 多人模式下若开局没拿到，可在任务书【新手礼包and游玩须知】补领

### 5. 次元之胃（整合包自制模组）

- 把食物放进**次元之胃**，会按食物的**饱食度**给予对应的属性加成
- 胃里食物总饱食度越高，加成越多
- ⚠ **每种食物的饱食度只能被计算一次** —— 同一种食物摆满也只算一次
- 用**末影箱果 / 天体洋葱 / 虹彩香蕉**升级次元之胃

### 6. 生命上限与农田

- **饱食度满之后继续进食，可以获得生命上限提升**
- **农田不再会被踩坏**

### 7. 食材获取的两个关键规则

- **作物的获取方式部分经过魔改** —— 请以任务书【作物图鉴】为准，不要按原模组的攻略找
- **大部分可获得食材的生物，用小刀类工具击杀会产生特殊掉落** —— 某种食材拿不到时，试着换小刀击杀对应生物

### 8. 其它

- **怪奇宝典**：把众多指南书编成一册。可将怪奇宝典与手中的指南书合成；手持怪奇宝典右键选择指南书，左键空气取消
- **战斗动作模组为 Better Combat**（更好的战斗），若影响游玩可自行删除
- **备份**：Simple Backups（简单备份），全量备份，位置 `.minecraft\versions\<版本名>\simplebackups`
- **新手小屋蓝图**：任务书【新手礼包】领取。右键地面预览（**建议关闭光影**），`Alt + 滚轮` 调位置，右键空气切换水平/垂直，**潜行 + 右键地面**完成放置

## 五、推进主线（最重要的引导）

任务书里有两个**没有分组**的特殊章节，是全局入口：

1. **新手礼包and游玩须知** —— 开局必看（上面那些机制都在这里）
2. **⭐指引-主线任务⭐** —— 64 个任务的推进路线图

主线里每个关键节点完成时，**会在商店解锁新的可购买物品**。所以主线不只是"进度"，还决定了玩家能买到什么。

详见 `main-quest.md`。

## 六、这个整合包的"魔改"特点（避免给错建议）

- **食物能当武器**：整合包有专门的 Boss 料理配方（`bossfoodrcp.js`），把料理做成强力武器是核心玩法
- **大量配方被移除**：为避免多个模组的同种作物重复，作者删掉了大量重复配方（`remove.js`）。所以「某个模组里明明有的配方」可能在本包中不存在
- **Alex 的洞穴已拆成六个独立维度**，不再是主世界的一个生物群系
- **作物有统一来源**：很多作物只能通过整合包指定的途径获得，不能按原模组的攻略找
- 有 **86 种自定义食物**（`vefc:` 命名空间）

## 七、她该怎么用这些知识

- 玩家问「XX 怎么获得」→ 先查 `tooltips.md`，再查 `item-names.json` + `quests.json`
- 玩家问「我该干嘛」→ 看 `main-quest.md`，结合玩家当前进度给下一步
- 玩家问「XX 是什么」→ 查 `item-names.json`（全量中英对照）
- 玩家问某个模组 → 查 `mods.md`
- **不知道就说不确定，不要编。** 但"基础问题"（上面第二章那些）必须知道
